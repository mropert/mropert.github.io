I have been a professional lecturer since 2017, delivering talks at multiple tech conferences each year
and can offer a range of existing training material or create one tailored to your needs.

I specialize in C++, performance, games and graphics. Listed below is a non-exhaustive sample of topics I
have covered before. Do not hesitate to get in touch if your topic isn't explicitly covered.

I also offer [consulting](/consulting) services.

You can also check out my [recorded conference talks](/about#talks) for a preview.

### C++ workshops

As an advocate of clean, modern and performant C++ code, I can run workshops focused on writing
good C++ using the newer releases of the language.

* Catching-up on C++ standards from C++11 to C++23
* Standard algorithms and containers
* Multithreading primitive building blocks, parallel algorithms and task-based programming
* Generic programming, template metaprogramming and concepts
* Data oriented design
* Profiling and performance optimization

### Game programming workshops

I have worked with multiple bespoke game engines as well as Unity and Unreal and can teach
C++ best practices specially tailored to the needs of game development (performance, stability and
iteration speed).

* Modern C++ for games
* Unity best practices
* Tick optimization and profiling
* Graphics programming for everyday gameplay programmers
